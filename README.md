 Executive SummaryThis project involved the deployment of a functional Security Information and Event Management (SIEM) environment utilizing the Wazuh open-source platform. The objective was to establish a centralized logging and monitoring system for a distributed environment, simulate an adversary attack (Brute Force), and analyze the resulting security telemetry to validate detection capabilities.2. Reflections & Lessons LearnedThrough this lab, I gained a deep understanding of the Log Pipeline:Generation: The OS creates an event log (Event ID 4625).Collection: The Wazuh Agent picks up the log and encrypts it.Ingestion: The Manager receives the log and compares it against pre-defined rules.Alerting: The Dashboard visualizes the threat for a SOC Analyst to investigate.This setup reinforces the importance of log correlation, as a single failed login is a non-event, but 10 failed logins within a minute is a security incident.
